# Stitch / AI Studio Imports

Place exported Google Stitch or AI Studio frontend files here before merging them
into Card Ledger.

Preferred export formats:

- A Stitch downloaded code `.zip`
- An AI Studio project `.zip`
- A folder containing `index.html`, CSS, JS, and image assets
- Any `DESIGN.md` or design resource files exported by Stitch

Current runnable app:

- Source: `outputs/`
- Local server: `npm run dev`
- URL: `http://127.0.0.1:4180/`
